## ✨ Что нового в 2.0

Версия 2.0 — это полный переход на новую техническую основу. Изменилось не только то, что под капотом, но и то, как программа выглядит и чем умеет помочь:

- **Доступ с телефона или второго экрана.** Тот же интерфейс можно открыть с другого устройства в домашней сети — например, держать программу на втором мониторе или телефоне рядом, пока летите.
- **Тонкий информационный бар для трансляций.** Полоска с позывным, маршрутом, погодой и статусом — удобно показывать зрителям на стриме, с настраиваемой прозрачностью фона.
- **Сигнализация FSA экономно работает с лимитом авиакомпании.** Если у вашей VA общий суточный лимit запросов к FSAirlines — программа укладывается в 5–10 запросов за рейс и показывает счётчик израсходованных запросов за сутки.
- **Зашифрованные файлы данных FSA для пилотов.** Директор авиакомпании может собрать VA ID, Pilot ID и API Key пилота в защищённый паролем файл и передать его — пилот просто импортирует файл и вводит пароль, не имея дела с сырым API-ключом.
- **Зашифрованное хранение токенов на диске.** Telegram Bot Token, Chat ID и FSA API Key хранятся в `config.json` в зашифрованном виде, а не открытым текстом — это снижает риск случайной утечки при передаче файлов или анализе антивирусом.
- **Умные уведомления о диспетчерах-Контролёрах по всему маршруту**, а не только на аэродромах вылета/прилёта. Программа анализирует весь навигационный маршрут (не только конечные точки) и заранее видит, через какие центры (Контроль/FSS) пройдёт полёт — полезно на длинных перелётах, где пилот не может следить за обстановкой часами.
- **Автоматическая проверка обновлений** через GitHub Releases — с уведомлением прямо в программе.
- **Сброс настроек одной кнопкой** с автоматическим перезапуском программы — полезно при сбоях или переустановке.
- **Telegram-уведомления** теперь сообщают не только о новых диспетчерах, но и о сигнализации FSA.

## ✈️ Возможности

### 📡 SimBrief

- Загрузка плана полёта по **Pilot ID**
- Автозаполнение: позывной, маршрут, эшелон, аэропорты вылета/прилёта/запасного
- Понятные сообщения об ошибках при неверном Pilot ID

### 🌦️ Погода (METAR)

- Загрузка METAR для аэропортов вылета, прилёта и запасного параллельными запросами
- Иконки погоды прямо в интерфейсе и в баре для стрима

### 🟢 Статус VATSIM

- Индикатор «вы в сети» — зелёная подсветка, когда ваш позывной виден в VATSIM
- Уведомление о появлении диспетчера на ваших аэродромах (включая Telegram)

### 🎙️ Фразы радиообмена

- Фразы для всех этапов полёта на русском и английском
- Режим **UNICOM** для полётов без диспетчеров
- **Создание собственных фраз**, экспорт и импорт наборов — можно делиться с другими пилотами

### 🔔 Сигнализация FSA

- Напоминает активировать рейс в клиенте FSAirlines перед движением, чтобы полёт не остался незасчитанным
- Экономно расходует лимит запросов API — подробности ниже

### 🔗 Подключение к симуляторам

- **MSFS 2020/2024** — через FSUIPC
- **X-Plane 12** — через XPlaneConnect
- Автоопределение запущенного симулятора, координаты, путевая скорость, курс, высота в реальном времени
- Понятное сообщение, если связь с симулятором потеряна (например, после краха MSFS), с автоматическим переподключением

## 💻 Установка

1. Скачайте `FRO_Assistant_2.exe` из раздела [Releases](https://github.com/decooper/FRO-Assistant-Releases/releases)
2. Запустите файл — откроется окно программы
3. Готово!

### Требования

- Windows 10 или 11 (64-bit)
- Для MSFS: [FSUIPC](https://www.fsuipc.com/)
- Для X-Plane: [XPlaneConnect](https://github.com/nasa/XPlaneConnect)

Если порт, который обычно использует программа, окажется занят другой программой — FRO Assistant автоматически подберёт свободный порт сама, без вашего участия.

## 🚀 Первый запуск

### 1. Введите Pilot ID

В верхней строке введите ваш **SimBrief Pilot ID** и нажмите **«Загрузить план»**.

### 2. Запустите симулятор

Программа сама определяет, что запущено — MSFS (через FSUIPC) или X-Plane (через XPlaneConnect). В нижней строке появится индикатор связи зелёного цвета и текущие данные полёта.

### 3. Настройте остальное по необходимости

Иконка **⚙** открывает настройки: язык, тема оформления, сигнализация FSA, Telegram, фразы.

## ⚙️ Настройка

Иконка **⚙** в верхней панели открывает все настройки программы:

- **SimBrief Pilot ID** — для загрузки плана
- **Тема оформления** — несколько тем оформления, применяются после перезапуска
- **Сигнализация FSA** — см. раздел ниже
- **Telegram-уведомления** — см. раздел ниже
- **Экспорт/импорт фраз**

Иконка **ℹ️** открывает окно «О программе» с информацией об авиакомпании UP! и кнопкой проверки обновлений.

## 🔔 Сигнализация FSA

Сигнализация напоминает активировать рейс в клиенте FSAirlines **перед** движением — чтобы самолёт не улетел, пока рейс не запущен в системе (иначе полёт не засчитается).

### Как получить данные для подключения

Каждому пилоту нужны три значения: **VA ID**, **Pilot ID** и **API Key**. Есть два способа их получить:

**Вариант А — вставить ссылку из браузера.** Откройте свой профиль на FSAirlines, скопируйте адрес из браузера (он содержит `va=...` и `p=...`) и вставьте в поле «Ссылка из профиля FSAirlines» в настройках — нажмите «Разобрать ссылку», и VA ID с Pilot ID заполнятся автоматически. API Key вводится вручную (его в ссылке нет).

**Вариант B — получить готовый файл от директора авиакомпании.** Директор может собрать все три значения в зашифрованный паролем файл через встроенный **Конструктор** (кнопка в настройках) и передать его пилоту вместе с паролем. Пилот нажимает «Импортировать файл от VA», выбирает файл, вводит пароль — данные подставляются автоматически, а сырой API Key пилот не видит. Это удобно, если директор хочет централизованно выдавать доступ, не раскрывая ключ API напрямую.

### Экономия лимита запросов

Если у вашей авиакомпании общий суточный лимит запросов к FSAirlines (например 300 запросов в сутки на всех пилотов сразу), программа экономит его жёстко: за типичный рейс расходуется **5–10 запросов**, не больше. Счётчик израсходованных за сегодня запросов отображается в нижней строке программы рядом с данными симулятора.

## 🗺️ Контроль по маршруту (для длинных перелётов)

На длинном перелёте (например через всю страну) пилот не может непрерывно следить за тем, какие диспетчеры-Контролёры появляются на трассе — особенно если рейс идёт несколько часов и пилот отвлёкся. FRO Assistant анализирует весь навигационный маршрут (не только аэропорты вылета и прилёта) и заранее знает, через какие центры (Контроль/FSS) пройдёт полёт.

Когда такой диспетчер появляется в сети VATSIM, программа определяет **два уровня**:

- 🔵 **Впереди по маршруту** — диспетчер появился, но до его зоны лететь ещё долго (дальше 50 морских миль или больше 15 минут по текущей скорости). Это тихая запись в журнале программы, без уведомлений — рано беспокоиться.
- 🔴 **На пути следования** — самолёт уже приблизился к зоне этого диспетчера. Приходит уведомление в Telegram (если оно настроено) с расстоянием и расчётным временем до зоны — самое время проверить связь.

Это и решает задачу «разбудить» пилота на длинном ночном перелёте: пока самолёт далеко от очередного центра, программа молчит, а когда зона действительно близко — присылает уведомление.

## 📱 Доступ с телефона и бар для стрима

В настройках есть раздел **«Доступ с телефона/второго экрана»** — там указан реальный адрес в локальной сети. Откройте этот адрес в браузере на телефоне или другом компьютере в той же Wi-Fi сети, чтобы видеть тот же интерфейс.

Отдельно есть **тонкий информационный бар** — полоска с позывным, маршрутом, погодой, статусом VATSIM и часами, удобная для показа на стриме. В настройках можно включить регулировку прозрачности фона бара — учтите, что прозрачность видна только при захвате через OBS (браузерный источник), в режиме «поверх игры» на вашем экране бар остаётся плотным — это ограничение системы, не ошибка.

## 💬 Telegram-уведомления

Программа может присылать сообщения в Telegram, когда:

- на вашем аэродроме (вылет/прилёт/запасной) появляется диспетчер VATSIM;
- срабатывает сигнализация FSA (вы начали движение, но не активировали рейс);
- по маршруту полёта приближается зона диспетчера-Контролёра (см. раздел «Контроль по маршруту»).

### Настройка

1. В Telegram напишите **@BotFather**, отправьте команду `/newbot` — получите **Bot Token**.
2. Напишите своему новому боту любое сообщение (иначе он не сможет отвечать вам).
3. Напишите **@userinfobot** (или **@id_bot**) — он пришлёт ваш **Chat ID**.
4. Вставьте оба значения в настройках программы, сохраните и нажмите **«Отправить тест»**.

Bot Token и Chat ID хранятся в `config.json` в зашифрованном виде, не открытым текстом.

## ✏️ Редактирование фраз

Можно **создавать собственные фразы** радиообмена и обмениваться ими с другими пилотами.

### Доступные переменные

`{callsign}` — позывной | `{departure}` — аэропорт вылета | `{arrival}` — аэропорт назначения
`{stand}` — стоянка | `{runway}` — ВПП | `{sid}` — SID | `{star}` — STAR
`{cruise_fl}` — эшелон | `{squawk}` — код ответчика | `{qnh}` — давление
`{fix}` — точка маршрута | `{freq}` — частота | `{heading}` — курс

### Экспорт и импорт

В настройках — кнопки **«Экспорт фраз»** и **«Импорт фраз»**. Экспорт сохраняет все фразы в файл, импорт заменяет текущие фразы содержимым файла. Так можно делиться своими наборами с другими пилотами.

## ❓ Частые вопросы

### Программа не подключается к симулятору

- **MSFS**: убедитесь, что FSUIPC запущен и работает
- **X-Plane**: убедитесь, что плагин XPlaneConnect установлен
- Если связь была, а потом пропала (например, симулятор крашнулся) — внизу появится сообщение «связь с симулятором потеряна», и программа сама попробует переподключиться

### Не отображается диспетчер VATSIM / индикатор «в сети»

- Убедитесь, что вы подключены к сети VATSIM (через vPilot/xPilot)
- Проверьте интернет-соединение

### Не работает сигнализация FSA

- Заполните VA ID, Pilot ID и API Key в настройках (вручную, по ссылке или через файл от директора)
- Убедитесь, что галочка «Включить сигнализацию» отмечена

### Я случайно всё сломал в настройках — что делать?

В настройках есть кнопка **«Сбросить настройки к заводским»**. Два нажатия с подтверждением — и программа удалит конфигурацию и автоматически перезапустится с чистыми настройками.

### Порт программы занят другим приложением

Программа определяет это сама и автоматически использует следующий свободный порт — никаких действий не требуется.

### Насколько защищены мои токены (Telegram, FSA API Key)?

Они хранятся в зашифрованном виде в `config.json`, не открытым текстом — это защищает от случайной утечки (например, если вы кому-то передадите архив с папкой настроек, или антивирус отправит файл на анализ). Это не криптостойкая защита от целенаправленной атаки на саму программу — такого уровня защиты программа не обещает, чтобы не требовать от вас вводить пароль при каждом запуске.
