## ✈️ Возможности

### 📡 SimBrief

- Загрузка плана полёта по **Pilot ID**
- Автозаполнение: позывной, маршрут, SID/STAR, эшелон, сквок
- Отображение ATIS для аэропортов вылета/прилёта/запасного

### 🌦️ Погода (METAR)

- Автоматическая загрузка METAR для аэропортов вылета, прилёта и запасного
- Анализ **15 типов опасных явлений**: гроза, обледенение, сдвиг ветра, туман, град и др.
- Иконки погоды в главном окне и компактных режимах
- Обновление каждые 10 минут

### 🟢 Статус VATSIM

- Цветные лампы для аэропортов вылета и прилёта:
  - 🟢 Зелёный — есть диспетчер (TWR/GND/APP/DEL)
  - 🟡 Жёлтый — только CTR (верхний контроль)
  - 🔴 Красный — диспетчеров нет
- Список ближайших диспетчеров
- Попутные рейсы на ваш аэропорт назначения

### 🎙️ Фразы радиообмена

- **ATC-режим**: 50+ фраз для всех этапов полёта (на русском и английском)
- **UNICOM-режим**: 14 фраз для полётов без диспетчеров
- Приоритет данных: ручной ввод → симулятор → план полёта
- Кнопка **"📋 Копировать"** для быстрой вставки в vPilot/xPilot
- **Создание собственных фраз** и обмен с другими пилотами

### 🔊 FSA Alert

- Звуковая сирена, если вы начали движение с забронированным рейсом FSAirlines, но забыли нажать **FLY**
- Автоматическое определение взлёта и посадки
- Квитирование тревоги одной кнопкой

### 🔗 Подключение к симуляторам

- **MSFS 2020/2024** — через FSUIPC7
- **X-Plane 12** — через XPlaneConnect
- Автоопределение запущенного симулятора
- Отображение в реальном времени: **FL (эшелон), GS (путевая скорость), HDG (курс)**

## 💻 Установка

### Готовый EXE (рекомендуется)

1. Скачайте `FRO_Assistant_vX.X.X.beta.exe` из раздела [Releases](https://github.com/decooper/FRO-Assistant-Releases/releases)
2. Запустите файл **от имени администратора** (правый клик → Запуск от имени администратора)
3. Готово! Никаких дополнительных установок не требуется.

### Требования

- Windows 10 или 11 (64-bit)
- Для MSFS: [FSUIPC7](https://www.fsuipc.com/)
- Для X-Plane: [XPlaneConnect](https://github.com/nasa/XPlaneConnect)

## 🚀 Первый запуск

### 1. Введите Pilot ID

В верхней строке введите ваш **SimBrief Pilot ID** (числовой идентификатор).

### 2. Загрузите план полёта

Нажмите кнопку **"Загрузить план"**. Программа загрузит данные из SimBrief и автоматически заполнит:

- Позывной
- Аэропорты вылета, прилёта, запасной
- SID, STAR, полосу, эшелон, сквок

### 3. Настройте симулятор

Нажмите **⚙** (шестерёнка) → выберите ваш симулятор:

- **Автоопределение** (рекомендуется)
- **Microsoft Flight Simulator (FSUIPC7)**
- **X-Plane 11/12 (XPlaneConnect)**

### 4. Подключитесь к симулятору

- Запустите симулятор
- В нижней строке программы появится **"xpc Connect"** или **"fsuipc Connect"** (зелёный цвет)
- В хедере отобразятся данные: **🟢 FL350 GS:250kt HDG:270°**

## ⚙️ Настройка

### Основные настройки (шестерёнка ⚙)

- **SimBrief Pilot ID** — ваш идентификатор
- **Nearby radius (nm)** — радиус поиска диспетчеров (по умолчанию 450 миль)
- **Poll interval (sec)** — интервал опроса VATSIM (по умолчанию 15 секунд)

### FSAirlines (требуется Root-доступ)

Для работы FSA Alert и лампы FSA:

1. Получите Root-доступ: меню **Правка → Root доступ** → введите пароль
2. В настройках заполните:
   - **FSA Pilot ID** — ваш ID пилота
   - **VA ID** — ID виртуальной авиакомпании
   - **API Key** — ключ API FSAirlines
3. Включите **Аудио оповещение**

### Режим и язык

- **ATC** — фразы для работы с диспетчером
- **UNICOM** — фразы для частоты 122.800 (без диспетчера)
- **Рус / Eng** — язык фраз

## 📖 Использование

### Этапы полёта

В левой панели 10 кнопок этапов:

1. **Деливери** — запрос разрешения на вылет
2. **Запуск** — запуск двигателей, буксировка
3. **Руление** — движение к ВПП
4. **Взлёт** — исполнительный старт, взлёт
5. **Выход** — набор высоты по SID
6. **Эшелон** — крейсерский полёт
7. **Снижение** — начало снижения
8. **Заход** — подход к аэропорту
9. **Посадка** — финальная прямая, посадка
10. **Стоянка** — освобождение ВПП, руление на стоянку

Переключать этапы можно:

- Кликом по кнопке
- Горячими клавишами: **Ctrl+→** (следующий) и **Ctrl+←** (предыдущий)

### Фразы радиообмена

1. Выберите этап полёта
2. Выберите позицию диспетчера (Деливери, Руление, Вышка, Круг, Подход, Контроль)
3. Нажмите на нужную фразу
4. Текст появится в нижнем поле
5. Нажмите **"📋 Копировать"**
6. Вставьте в vPilot/xPilot (Ctrl+V)

### Ручной ввод точки и эшелона

- **Точка:** — введите название точки маршрута (например, NANUD)
- **Эшелон:** — введите крейсерский эшелон (например, 350)
- Эти значения имеют **высший приоритет** при генерации фраз

### FSA Alert

Если рейс забронирован на FSAirlines, но вы не нажали **FLY**:

- Лампа FSA горит **красным**
- При начале движения (GS > 2 узла в течение 10 секунд) — **звучит сирена**
- Нажмите кнопку **"ТРЕВОГА"** (мигает красным) для квитирования
- Нажмите **"Сброшена"** для полного сброса

## ✏️ Редактирование фраз

FRO Assistant позволяет **создавать собственные фразы** радиообмена и **обмениваться ими** с другими пилотами.

### Как добавить свою фразу

1. Получите **Root-доступ** (меню Правка → Root доступ)
2. Нажмите кнопку **"➕ Добавить фразу"**
3. Введите ключ фразы (английскими буквами, например: `request_startup`)
4. Введите текст фразы с переменными (например: `{departure}-{position}, {callsign}, разрешите запуск на стоянке {stand}`)
5. Нажмите **Сохранить**

### Доступные переменные

`{callsign}` — позывной | `{departure}` — аэропорт вылета | `{arrival}` — аэропорт назначения
`{stand}` — стоянка | `{runway}` — ВПП | `{sid}` — SID | `{star}` — STAR
`{cruise_fl}` — эшелон | `{squawk}` — код ответчика | `{qnh}` — давление
`{fix}` — точка маршрута | `{freq}` — частота | `{heading}` — курс

### Экспорт и импорт фраз

- **Экспорт:** меню Файл → Сохранить конфиг (фразы) — сохраняет все фразы в JSON-файл
- **Импорт:** меню Файл → Загрузить конфиг (фразы) — загружает фразы из JSON-файла
- Вы можете **делиться** своими наборами фраз с другими пилотами

### Сброс к стандартным

Меню Правка → Сбросить фразы к стандартным — возвращает все фразы к заводским настройкам.

## 📱 Компактные режимы

### Компактное окно (кнопка 📱)

Минималистичное окно только с самой важной информацией:

- Позывной + данные симулятора
- Иконки погоды DEP/ARR/ALT
- Индикатор FSA
- **Можно перетаскивать по экрану**
- **Всегда поверх других окон**
- Закрыть ✕ → возврат к полному окну

### TopBar (кнопка 📊)

Тонкая полоска на всю ширину экрана (как menu bar):

- Позывной + данные симулятора
- DEP/ARR/ALT с цветными точками погоды
- FL, GS, HDG
- FSA индикатор
- Статус VATSIM (DEP/ARR)
- **Трафик: до 5 ближайших бортов в радиусе 20 миль**
- UTC часы
- **Прижата к верхнему краю экрана**

## ❓ Частые вопросы

### Программа не подключается к симулятору

- **MSFS**: убедитесь, что FSUIPC7 запущен и работает
- **X-Plane**: убедитесь, что плагин XPlaneConnect установлен в `Resources/plugins/`
- Попробуйте кликнуть по строке **"Data Link"** внизу окна для переподключения

### Не отображаются диспетчеры VATSIM

- Убедитесь, что вы подключены к сети VATSIM (через vPilot/xPilot)
- Проверьте интернет-соединение
- Данные обновляются каждые 15 секунд (интервал можно изменить в настройках)

### Фразы генерируются с ошибками

- Загрузите план полёта через SimBrief (кнопка "Загрузить план")
- Проверьте, что поля "Точка" и "Эшелон" заполнены или пустые (по необходимости)
- Проверьте выбор языка (Рус/Eng)

### Не работает FSA Alert

- Получите Root-доступ (Правка → Root доступ)
- Заполните данные FSAirlines в настройках
- Включите аудио оповещение

### Как получить Root-доступ?

- Root-пароль можно запросить у автора программы
- Root-доступ открывает: редактирование фраз, настройки FSA, импорт/экспорт
